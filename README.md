# PDF-CSV-Extractor
A web application designed for converting scanned or digital PDF tables into CSV files using vector extraction (pdfplumber) or OCR extraction (cv2 and pytesseract).

To start the webpage, go to ..\PDF_CSV_Extractor\dist and double click on Extractor.exe

If that does not work you need to regenerate the .exe file, to do this follow the following steps
 1. go to ..\PDF_CSV_Extractor and open the command prompt in this folder
 2. type the commands in ..\PDF_CSV_Extractor\commands.txt one by one 
 3. go to ..\PDF_CSV_Extractor\dist and double click on Extractor.exe

While running the Extracter.exe and it does not load or shuts down without any error message, then copy and paste the launcher.bat file in ..\PDF_CSV_Extractor\dist folder and run .bat file first; This will generate an error_log.txt
